# Terno

Standalone web application binaries. Download your platform from [Releases](https://github.com/terno-projects/terno/releases).

Run the executable and open http://localhost:7200. Set PORT to override the port. Linux and macOS require chmod +x.

Supports Linux, macOS, and Windows on amd64 and arm64. macOS binaries are unsigned and not notarized; Windows binaries are unsigned.

This repository distributes binaries only; application source is not published here. The interface is an independent Termius-inspired website preview, not an official Termius service. SSH and registration are demonstrations only.
